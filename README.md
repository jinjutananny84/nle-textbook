# nannie compre website (NLE Step 1)

เว็บอ่านคู่กับชีท A3 สรุป NLE Step 1 · เปิดที่ https://jinjutananny84.github.io/nle-textbook/

เลขหัวข้อในเว็บตรงกับเลขกล่องในชีท A3 แบบ 1 ต่อ 1

## เพิ่มบทใหม่ (ไม่ต้องแตะโค้ด)
1. เขียน `data/<id>.md` ตามรูปแบบใน `FORMAT.md`
2. ใส่ข้อสอบใน `data/<id>-exams.json`
3. เพิ่มบรรทัดใน `data/chapters.json` (ใส่ตรงไหนก็ได้ เว็บจะเรียงตามเลขบทให้เอง)

ความคืบหน้า (ติ๊กเข้าใจแล้ว) กองข้อผิด และ flashcard ที่จำได้ เก็บในเบราว์เซอร์ของแต่ละเครื่อง (localStorage)
