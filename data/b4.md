#### ผิวหนังคือ "กำแพงอิฐ" ที่สร้างใหม่ตลอดเวลา

หน้าที่หลักของผิวคือกันน้ำออกและกันเชื้อเข้า หน้าที่นี้ทำโดย **keratinocyte (~80% ของเซลล์ใน epidermis)** ที่เกิดจาก stem cell ใน basal layer แล้วค่อย ๆ ถูกดันขึ้นด้านบน ระหว่างทางเซลล์ "เปลี่ยนอาชีพ" ทีละชั้น (keratinization) จนสุดท้ายตายกลายเป็นแผ่นเกล็ดที่อัดแน่นด้วย keratin ดังนั้นถ้าจำว่าแต่ละชั้นกำลัง "ทำอะไร" จะตอบโจทย์ได้ทุกแบบ

`Basale (แบ่งตัว) → Spinosum (ยึดกันด้วย desmosome) → Granulosum (สร้าง keratohyalin + lamellar body) → Corneum (ตาย อัดเป็นกำแพง)`

| ชั้น | สิ่งที่เห็น | หน้าที่ · จุดสอบ |
|---|---|---|
| Stratum basale | เซลล์แถวเดียวบน BM · stem cell · melanocyte · Merkel | ==stem cell (stratum germinativum)== · keratin ==K5/K14== |
| Stratum spinosum | desmosome ทำให้เห็นเป็น "หนาม" · มี Langerhans | ต้านแรงกล · keratin ==K1/K10== |
| Stratum granulosum | keratohyalin granule (basophilic) + ==lamellar body== | หลั่ง ceramide/phospholipid/sterol = กาวกันน้ำ |
| Stratum lucidum | ชั้นใสบาง | มีเฉพาะ ==thick skin ฝ่ามือฝ่าเท้า== |
| Stratum corneum | corneocyte ไม่มี nucleus + lipid | ==brick and mortar== · barrier ด่านแรก |

- **Malpighian layer** = คำเก่า หมายถึง basale + spinosum รวมกัน (ข้อสอบเก่าใช้เป็นตัวหลอก)
- **Transit time 28 วัน** = basal → corneum 14 วัน + ค้างใน corneum อีก 14 วันก่อนหลุด → เป็นเหตุผลที่ยาทาเชื้อราต้องทาต่อ ~4 สัปดาห์ให้ผิวชั้นที่ติดเชื้อหลุดออกหมด

### Keratin pair: กลไกของโรคตุ่มน้ำจากพันธุกรรม
Keratin เป็น intermediate filament ที่ต้องจับคู่ (acidic + basic) ถ้าคู่ไหนกลายพันธุ์ เซลล์ชั้นนั้นจะเปราะแตกเมื่อโดนแรงเสียดสี
- ==K5/K14== เสีย → **epidermolysis bullosa simplex** แยกใน basal layer ([[3]])
- ==K1/K10== เสีย → **epidermolytic hyperkeratosis** (bullous congenital ichthyosiform erythroderma) เซลล์ spinous แตก + ผิวหนาเป็นเกล็ด (ข้อ 75.2/97)

### Ichthyosis: เมื่อการลอกของ corneum เสีย {S}
Ichthys = ปลา หมายถึงผิวเป็นเกล็ดปลา เกิดจาก kinetics ของการสร้าง/การหลุดของ corneum ผิดปกติ (จาก Phase Outcome)

| โรค | ยีน/กลไก | Keyword |
|---|---|---|
| Ichthyosis vulgaris | ==FLG (filaggrin)== | พบบ่อยสุด อาการเบา ขุยขาวที่ขา ด้าน extensor เว้นข้อพับ · สัมพันธ์ atopic |
| X-linked ichthyosis | ==steroid sulfatase (STS)== | ชาย แรกเกิด เกล็ดใหญ่สีเข้ม รวมข้อพับ · corneal opacity รูปจุลภาค |
| Lamellar ichthyosis (ARCI) | TGM1 ฯลฯ (cornified envelope) | เกล็ดใหญ่สีเข้มเป็นแผ่น · แรกเกิดเป็น ==collodion baby== |
| Harlequin ichthyosis | ==ABCA12== (lamellar granule ส่ง lipid ไม่ได้) | แผ่นเกราะหนา ร่องแดงลึก ใบหูหาย ตายเร็ว ("เด็กดักแด้") |
| Epidermolytic ichthyosis | ==K1/K10== | แรกเกิดมีตุ่มน้ำ แดง ลอก |

?? ทำไมผิวที่ถลอก (abrasion) ติดเชื้อง่ายทั้งที่ Langerhans ยังอยู่ :: เพราะด่านแรกที่กันเชื้อคือ stratum corneum ที่เป็นกำแพงทางกายภาพ ไม่ใช่ภูมิคุ้มกัน เมื่อกำแพงหายเชื้อก็เข้าได้ทันที
?? ทำไม KOH พบ septate hyphae แล้วต้องทายาราว 4 สัปดาห์ :: เชื้อ dermatophyte อยู่ใน corneum ต้องรอให้ผิวที่ติดเชื้อถูกแทนที่หมด ซึ่งใช้เวลาหนึ่งรอบ turnover ≈ 28 วัน

!! Abrasion ติดเชื้อ → ตอบ ==stratum corneum== อย่าตอบ Langerhans
!! ทารก epidermolytic hyperkeratosis (K1/K10) → เซลล์ ==spinous== · ถ้าเป็น K5/K14 = basal (EB simplex) (ข้อ 75.2/97)
!! Harlequin ichthyosis ถามเซลล์ที่ผิดปกติ → ==keratinocyte== (lamellar granule เป็นของ keratinocyte)

>> อ.ยกข้อสอบ: ขูด KOH เจอ septate hyphae ทายาต้องนานเท่าไรผิวจึงกลับปกติ → ==28 วัน== (turnover)
>> Callus = corneum หนาจากเสียดสี ไม่เจ็บ · Corn (ตาปลา) = มี hard central core เจ็บ

## 2 | เซลล์ใน epidermis · ที่มา (embryology)
freq: 2/6
stars: 3
kw: neural crest | Birbeck granule | CD1a S100 | epidermal-melanin unit | surface ectoderm | mesenchyme
card: Melanocyte มาจาก germ layer ใด อยู่ชั้นไหน :: Neural crest · stratum basale
card: Langerhans cell มาจากไหน อยู่ชั้นไหน :: Bone marrow (monocyte/dendritic lineage) · stratum spinosum
card: Marker และ granule ของ Langerhans :: CD1a, S100 · Birbeck granule รูป tennis racket
card: Merkel cell ทำหน้าที่อะไร :: Touch (slowly adapting mechanoreceptor) อยู่ basale · มะเร็ง Merkel cell (MCPyV)
card: Ectodermal dysplasia เซลล์ใดยังปกติ :: Langerhans (มาจาก bone marrow ไม่ใช่ ectoderm)
card: Epidermis/ขน/เล็บ/ต่อม vs dermis มาจาก :: Surface ectoderm · dermis/hypodermis = mesoderm (mesenchyme)
card: Facial hemangioma ในทารกมาจาก germ layer ใด :: Mesoderm (ข้อ 79/29)

#### ผิวหนัง = งานประกอบของ 3 แหล่ง
Epidermis ไม่ได้มีแต่ keratinocyte แต่เป็นที่อยู่ของ "ผู้เช่า" ที่อพยพมาจากที่อื่นตอนเป็นตัวอ่อน ข้อสอบชอบถามว่า ==ถ้าโรคทำลายแหล่งหนึ่ง เซลล์ไหนยังปกติ==

| เซลล์ | %/ชั้น | ที่มา · จุดสอบ |
|---|---|---|
| Keratinocyte | 80% ทุกชั้น | ==surface ectoderm== · barrier ด่านแรก (ถูกทำลายใน burn แล้วติดเชื้อ) |
| Melanocyte | 5–10% basale | ==neural crest== · dendrite ส่ง melanosome ให้ keratinocyte ~36 เซลล์ = epidermal-melanin unit |
| Langerhans | spinosum | ==bone marrow== (monocyte lineage) · APC · ==Birbeck granule== (tennis racket) · CD1a, S100 |
| Merkel | <1% basale | touch (slowly adapting) · neural crest/epidermal · มะเร็ง Merkel cell (MCPyV) |
| IEL | น้อยมาก | CD8 γδ T cell ทำงานแบบ innate |

- {S} Embryo: epidermis/ขน/เล็บ/ต่อม = **surface ectoderm** · dermis/hypodermis = **mesoderm (mesenchyme)** · melanocyte = **neural crest** · Langerhans = **bone marrow**
- Hemangioma/port-wine stain/lymphangioma = ความผิดปกติของหลอดเลือด → ==mesoderm== (ข้อ 79/29)
- Professional APC = ==dendritic cell · B cell · macrophage==

?? ทำไมผู้ป่วย albinism ถามเซลล์ต้นกำเนิดยังตอบ neural crest :: เพราะใน albinism จำนวน melanocyte ปกติ เพียงแต่ tyrosinase เสีย เซลล์ที่ผิดปกติจึงยังเป็น melanocyte ซึ่งมาจาก neural crest ดู [[14]]

!! Langerhans อยู่ ==epidermis (spinosum)== ไม่ใช่ dermis — ข้อจับคู่ macrophage/APC กับตำแหน่ง ตัวเลือกที่ถูกคือ macrophage–ม้าม (ข้อ 74.1/45)
!! เซลล์ส่วนใหญ่ของ connective tissue (fibroblast, adipocyte ฯลฯ) มาจาก ==mesenchyme== (ข้อ 74.2/75)
!! Ectodermal dysplasia ("โรคสังข์ทอง" ไม่มีเหงื่อ ฟันน้อย ขนบาง) ถามเซลล์ที่ยังปกติ → ==Langerhans==

## 3 | Cell junction · PV vs BP · ระดับการแยกตุ่มน้ำ
freq: 2/6
stars: 3
kw: acantholysis | tombstone | Nikolsky | Dsg3 vs Dsg1 | BP180 | linear IgG | col VII | fishnet
card: Desmosome ยึดอะไรกับอะไร โปรตีนหลัก :: เซลล์–เซลล์ · desmoglein 1/3, desmocollin · plakoglobin/desmoplakin ต่อกับ keratin
card: Hemidesmosome ยึดอะไร โปรตีนหลัก :: เซลล์–basement membrane · BP180 (col XVII), BP230, integrin α6β4
card: Pemphigus vulgaris: Ab ต่อ · ระดับแยก · DIF :: IgG ต่อ desmoglein 3 (±1) · suprabasal acantholysis (tombstone) · intercellular "fishnet"
card: Bullous pemphigoid: Ab ต่อ · ระดับแยก · DIF :: IgG ต่อ BP180/BP230 · subepidermal + eosinophil · linear IgG/C3 ที่ BMZ
card: PV vs BP ทางคลินิก :: PV 40–60 ปี flaccid แตกง่าย เยื่อบุ (เหงือกนำ) Nikolsky+ · BP >60 ปี tense คันนำ mucosa น้อย Nikolsky−
card: Dermatitis herpetiformis :: IgA granular ที่ dermal papillae · gluten (celiac) · ตุ่มคันมาก ศอก ก้น
card: Dystrophic EB ผิดที่โปรตีนใด :: Collagen VII (anchoring fibril)
card: SSSS / pemphigus foliaceus แยกระดับไหน :: Subcorneal/granular (Dsg1) ไม่มี mucosa

#### หลักคิด: ตุ่มน้ำแตกง่ายหรือไม่ ขึ้นกับ "หลังคา" หนาแค่ไหน
ผิวหนังยึดกันด้วยหมุด 2 แบบ: **desmosome** ยึดเซลล์กับเซลล์ (ในชั้น spinosum) และ **hemidesmosome** ยึดเซลล์ basal กับ basement membrane ถ้ามี antibody/toxin/การกลายพันธุ์ไปทำลายหมุดตัวไหน ผิวก็แยกที่ระดับนั้น

`ยิ่งแยกตื้น → หลังคาบาง → flaccid แตกง่าย Nikolsky+ · ยิ่งแยกลึก → หลังคาเป็น epidermis ทั้งแผ่น → tense`

### Pemphigus vulgaris vs bullous pemphigoid

| | Pemphigus vulgaris | Bullous pemphigoid |
|---|---|---|
| อายุ | 40–60 | ==>60== (พบบ่อยกว่า) |
| ตุ่ม | ==flaccid== แตกง่าย · erosion | ==tense== · คันนำ (urticarial) |
| Mucosa | พบบ่อย (==เหงือกนำ==) | น้อย |
| Nikolsky | + | − |
| Ab | IgG → ==desmoglein 3== (±1) | IgG → ==BP180/230== (hemidesmosome) |
| Histo | ==suprabasal acantholysis== · tombstone | ==subepidermal + eosinophil== |
| DIF | intercellular ==fishnet== | ==linear IgG/C3== ที่ BMZ |

- ทั้งคู่เป็น ==type II hypersensitivity== (Ab จับ Ag บนเซลล์/โครงสร้าง) ดู [[16]]
- Tzanck smear ใน PV = ==acantholytic cell== (กลม cytoplasm basophilic) ดู [[32]]
- อื่น ๆ: **DH** = IgA granular ที่ dermal papillae + gluten · **EB dystrophic** = col VII · **SSSS** แยก subcorneal (Dsg1) ไม่มี mucosa ([[23]])

?? ทำไม SSSS ไม่มีแผลในปาก ขณะที่ PV มีแผลในปากเด่น :: เยื่อบุช่องปากใช้ Dsg3 เป็นหลัก ส่วน exfoliative toxin ของ S. aureus ตัดเฉพาะ Dsg1 ซึ่งเด่นในผิวชั้นตื้น เยื่อบุจึงรอด ในขณะที่ PV มี Ab ต่อ Dsg3 จึงลอกที่เหงือกก่อน
?? Blister ส้นเท้าจากรองเท้ากัดแยกที่ไหน :: Desmosome ในชั้น spinosum จาก mechanical stress เป็นตุ่มน้ำ intraepidermal ไม่มี inflammation

!! ตุ่มน้ำเยื่อบุปาก+รักแร้ แยกใน spinosum → โครงสร้างที่เสีย = ==desmosome (Dsg3/1)== (ข้อ 77/104)
!! เป้าของ bullous pemphigoid → ==hemidesmosome (BP180/230)== (ข้อ 74.1/91)
!! EB simplex ผิดปกติที่ ==stratum basale (K5/K14)== (ข้อ 74.1/61)
!! ดูรูป DIF: intercellular → PV · linear → BP · granular IgA ที่ papillae → DH

## 7 | สรีรวิทยาเหงื่อ · heat acclimatization · thermoregulation
freq: 3/6
stars: 3

card: ทำไมเหงื่อเป็น hypotonic :: Secretory coil หลั่ง isotonic แล้ว duct ดูด Na⁺/Cl⁻ กลับ (CFTR, ENaC) น้ำตามไม่ทัน
card: Heat acclimatization เปลี่ยนเหงื่ออย่างไร :: ออกเร็วขึ้น ปริมาณมากขึ้น แต่เจือจางลง (Na ต่ำ) จาก aldosterone ↑ · plasma volume ↑
card: Cystic fibrosis เหงื่อเป็นอย่างไร :: เค็ม (sweat Cl > 60 mmol/L) เพราะ CFTR เสีย duct ดูด Cl⁻ กลับไม่ได้
card: ขนลุกตอนหนาวมีประโยชน์อย่างไร :: Heat insulation (กักชั้นอากาศ) ไม่ใช่ heat production (ข้อ 77/113)
card: Fever vs heat stroke :: Fever = set point สูง (PGE2) ยาลดไข้ได้ผล · heat stroke = set point ปกติแต่ระบายไม่ทัน ยาลดไข้ไม่ได้ผล ต้อง cooling
card: Heat stroke การรักษาที่ไม่ควรทำ :: ให้ paracetamol (ข้อ 74.2/52)

#### Eccrine gland: สร้างแบบ isotonic แล้ว "เก็บเกลือคืน"

`Secretory coil หลั่ง isotonic (คล้าย plasma) → ท่อ (duct) ดูด Na⁺/Cl⁻ กลับผ่าน ENaC/CFTR → เหงื่อที่ออกมา hypotonic`

ความเค็มของเหงื่อจึงขึ้นกับ 2 อย่าง: **เวลาที่ท่อมีให้ดูดกลับ** (เหงื่อไหลเร็ว → ดูดไม่ทัน → เค็มขึ้น) และ **aldosterone** ที่เพิ่มจำนวน ENaC ในท่อ (คล้ายที่ไต)

### Heat acclimatization (ย้ายจากเขตหนาวไปเขตร้อน 1–2 สัปดาห์)
- เหงื่อ ==ออกเร็วขึ้น (threshold ต่ำลง) + ปริมาณมากขึ้น==
- ==aldosterone ↑== → duct ดูด NaCl กลับมากขึ้น → เหงื่อ ==เจือจางลง (Na ต่ำ)== → ประหยัดเกลือ
- plasma volume ↑ · HR ขณะทำงานต่ำลง

### Cystic fibrosis
CFTR เสีย → ท่อดูด Cl⁻ กลับไม่ได้ (Na⁺ ก็ดูดกลับน้อยตาม) → ==เหงื่อเค็ม sweat Cl > 60 mmol/L== = sweat chloride test ใช้วินิจฉัย {X}

### Thermoregulation
- **ร้อน** → vasodilation ผิว + เหงื่อ (ระบายด้วย evaporation เป็นหลักเมื่ออากาศร้อนกว่าร่างกาย)
- **หนาว** → vasoconstriction + shivering (สร้างความร้อน) + ==piloerection== (ในสัตว์ขนตั้งกักชั้นอากาศ = ==insulation==)
- **Fever vs heat stroke**: fever = hypothalamic ==set point สูง (PGE2)== → antipyretic ได้ผล · heat stroke = set point ปกติแต่ระบายไม่ทัน → ==antipyretic ไม่ได้ผล== ต้อง cooling เร็ว (ice water, evaporative)

?? ทำไมคนที่เพิ่งย้ายไปเมืองร้อนเหงื่อจะ "เจือจางลง" ไม่ใช่ "เค็มขึ้น" ทั้งที่ออกมากขึ้น :: เพราะ aldosterone เพิ่มขึ้นจากการเสียเกลือ ทำให้ท่อดูด NaCl กลับมากกว่าปริมาณที่เพิ่ม ร่างกายจึงเก็บเกลือไว้ได้
?? ทำไมให้ paracetamol ใน heat stroke ไม่ได้ผล :: paracetamol ลด PGE2 ที่ยก set point แต่ heat stroke set point ไม่ได้สูง ความร้อนเกิดจากระบายไม่ทัน และยาอาจเป็นพิษต่อตับที่บาดเจ็บอยู่แล้ว

!! ย้ายจากเขตหนาวมาเขตร้อน เหงื่อ → ==more dilute + ปริมาณมากขึ้น== · ตัวหลอก more salty / more oily (ข้อ 74.2/96, 74.2/100)
!! ข้อถูกของ eccrine gland → ควบคุมการขับ electrolyte (duct ดูด NaCl กลับ → hypotonic) (ข้อ 75.2/125)
!! ขนลุกตอนหนาว ประโยชน์ = ==heat insulation== ไม่ใช่ heat production (ข้อ 77/113)
!! Heat stroke สิ่งที่ไม่ควรทำ = ==ให้ paracetamol== (ข้อ 74.2/52)

#### หายแบบ regeneration หรือ scar ขึ้นกับ "โครง ECM"
- **Regeneration**: เซลล์ labile/stable + ==ECM ยังอยู่== → กลับเหมือนเดิม (ผิวทารกในครรภ์หายไม่มีแผลเป็น)

- Acute wound < 4 สัปดาห์ · chronic wound > 4 สัปดาห์ (ลำดับขั้นเสีย)

### 3 ระยะ
`Inflammation (0–3 วัน: platelet, neutrophil → macrophage) → Proliferation (3 วัน–3 สัปดาห์: granulation tissue, VEGF angiogenesis, re-epithelialization, myofibroblast contraction) → Remodeling (col III → col I โดย MMP; 3 สัปดาห์–1 ปี)`

- ==Granulation tissue = fibroblast (หลัก) + new capillary + macrophage== · แผลกดทับดีขึ้นเพราะ granulation tissue · ตอบ ==fibroblast== ไม่ใช่ smooth muscle
- Myofibroblast = wound contraction (secondary intention หดมาก)
- Tensile strength: 1 สัปดาห์ ~10% · 3 เดือน ~70–80%
- Primary intention (เย็บ) · secondary (ปล่อยหายเอง contraction มาก) · {S} tertiary/delayed primary (รักษาติดเชื้อก่อนแล้วค่อยเย็บ)

| Growth factor | หน้าที่ |
|---|---|

| PDGF | ดึง fibroblast/SMC เข้ามา |
| VEGF | angiogenesis |
| FGF | angiogenesis + fibroblast |

### Addison disease (primary adrenal insufficiency) {X}
`ต่อมหมวกไตถูกทำลาย → cortisol ↓ → ไม่มี negative feedback → POMC ↑ → ACTH + α-MSH ↑ → MC1R บน melanocyte → ผิว/เยื่อบุแก้ม/รอยพับ/แผลเป็นคล้ำ`

- **Aldosterone ↓** → ==Na↓ K↑== ความดันต่ำ อยากกินเค็ม · ==renin ↑==
- **Cortisol ↓** → glucose ↓ อ่อนเพลีย เบื่ออาหาร น้ำหนักลด
- ตรวจ: ==ACTH stimulation แล้ว cortisol ไม่ขึ้น== · ACTH สูง
- สาเหตุในไทย: autoimmune, ==TB==
- **Secondary** (Sheehan/pituitary): ACTH ต่ำ → ==ไม่คล้ำ== · aldosterone ปกติ (RAAS ไม่ขึ้นกับ ACTH) → K ปกติ

### ระยะโรค
- **Primary** (~3 สัปดาห์): ==chancre ไม่เจ็บ ขอบแข็ง== + LN โต (vs ==chancroid H. ducreyi = เจ็บ ขอบนุ่ม==) → ตรวจเชื้อโดยตรง = ==dark-field microscopy== (หรือ PCR) · serology อาจยังลบ

### Conjunctivitis และ keratitis {S}
- Conjunctivitis = vascular dilation · cellular infiltration · exudation · chemosis · ตาแดง เคืองเหมือนมีผง ขี้ตา เปลือกตาติด · acute < 3 สัปดาห์ · chronic ≥ 3 สัปดาห์
- **Papillary response** (ตุ่มมีแกนหลอดเลือด) = allergic, bacterial, contact lens · **Follicular response** (ก้อน lymphoid) = viral, chlamydia
- **Ophthalmia neonatorum**: 2–5 วันหลังคลอด หนองมาก = ==N. gonorrhoeae== (ป้องกันด้วย erythromycin/tobramycin ointment) · 5–14 วัน = chlamydia
- **Infectious keratitis**: ปวด (nerve ending โผล่) · ตามัว · น้ำตาไหล · กลัวแสง · blepharospasm · เชื้อ bacteria/virus (HSV dendritic ulcer)/fungus/Acanthamoeba (contact lens)

### Glaucoma {S}
`Aqueous humor สร้างที่ ciliary body → posterior chamber → pupil → anterior chamber → ไหลออกทาง trabecular meshwork → Schlemm canal (หลัก) หรือ uveoscleral pathway · outflow อุดตัน → IOP ↑ → optic disc cupping + เสียลานสายตาด้านข้าง`
